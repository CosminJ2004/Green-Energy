# ADR-0001: Record architecture decisions

Status: Accepted | Date: 2026-10-17

## Context
The project is planned in docs that guide implementation, and decisions will change as spikes resolve unknowns.

## Decision
Record significant decisions as ADRs in `docs/adr/` (numbered, one per decision) with Status (Proposed / Accepted / Superseded), Context, Decision and Consequences. Superseded ADRs stay in place and link to their replacement. Docs in `docs/` are updated in the same change as the ADR.

## Consequences
Decision history is tracked in git and implementation can be checked against it.
